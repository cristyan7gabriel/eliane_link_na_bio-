# 🌟 Eliene Matos | Estética Avançada & Cuidados Capilares

Centralizador de links e bio de alto padrão desenvolvido exclusivamente para a esteticista e cabeleireira **Eliene Matos** em Goiânia - GO.

Com mais de 26 anos de trajetória na área da beleza e autoestima feminina, este projeto apresenta uma identidade visual luxuosa baseada em sua logomarca (preto ônix, dourado metálico e verde folhagem), integrando:
- Agendamento direto no WhatsApp com seleção de procedimento
- Procedimentos faciais e capilares com links pré-formatados
- Endereço físico e rota no Google Maps (Setor Aeroporto)
- Chave Pix com cópia em 1 clique
- Download de Cartão de Contato (vCard .vcf)
- Modal com QR Code oficial
- Alternador de Modo Noturno Luxo / Modo Claro Editorial

## 🚀 Como Fazer Deploy na Vercel

O projeto já está 100% configurado com `vercel.json` e Vite:

1. Acesse [vercel.com](https://vercel.com) e faça login.
2. Clique em **"Add New..."** ➔ **"Project"**.
3. Importe o repositório `eliane_link_na_bio-`.
4. A Vercel detectará automaticamente as configurações através do `vercel.json`:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Clique em **"Deploy"**.
